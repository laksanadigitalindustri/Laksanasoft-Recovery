# Laksanasoft Custom Recovery for Samsung Galaxy S10+ (`beyond2lte`)

Supercharged custom TWRP/OrangeFox Recovery compiled via GitHub Actions for Samsung Galaxy S10+ (`beyond2lte`, Exynos 9820).

## 🚀 Features

- ⚡ **Signature Verification Bypass**: Auto-accepts all ZIP packages (NetHunter, APatch, Custom Kernels) without warnings or prompts.
- 🛡️ **APatch & Magisk Native Helper**: Built-in compatibility for APatch and Magisk modules.
- 🐉 **NetHunter Rescue Tools**: Pre-installed `nh-rescue` script inside recovery shell to mount Kali Chroot directly.
- 🔓 **ADB Root Access**: Default `ro.debuggable=1`, `ro.adb.secure=0`, `ro.secure=0` for instant root access over ADB.
- 📦 **Dual Output**: Compiles both `recovery.img` and Odin-flashable `recovery.tar`.

## 🛠️ How to Build via GitHub Actions

1. Go to **Actions** tab in this GitHub repository.
2. Select **Build Feature-Rich Custom Recovery (Samsung Galaxy S10+)**.
3. Click **Run workflow**.
4. Download `Laksanasoft-NetHunter-Custom-Recovery-beyond2lte` build artifacts when finished!
